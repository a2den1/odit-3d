# ODIT 3D

3D 장면을 만들고, 타임라인에서 샷·자막·효과·음악을 얹어 바로 영상으로 뽑는 데스크탑 앱.

- **모델링**: 기본 도형 12종, 3D 글자(한글), 조명, 카메라, GLB·GLTF·FBX·OBJ·STL 가져오기
- **정점 편집 모드** (`Tab`): 정점/면 선택, 박스 선택, `G` `R` `S` 변형과 X·Y·Z 축 고정, `E` 돌출, `M` 병합, 세분화, 삭제
- **애니메이션**: 모든 값에 키프레임, 41가지 움직임 곡선, 자동 키, 모션 프리셋
- **타임라인**: 카메라 샷(컷·암전·카메라 이동 전환), 자막, 효과 12종, 오디오
- **프리뷰 패널**: 3D 화면 옆(또는 아래)에 완성 화면을 따로 띄워 편집하면서 바로 확인
- **블렌더 파일에서 시작**: .blend를 열면 설치된 블렌더로 장면을 뽑아 오브젝트·카메라·조명·키프레임·렌더 설정까지 가져옴
- **설정**: 마우스 조작, 화면 선명도, 자동 저장, 기본 움직임 곡선, 블렌더 위치
- **내보내기**: MP4 · WebM · GIF · PNG

## 개발

```bash
npm install
npm start          # 빌드 후 실행
npm run selftest   # 자동 점검
npm run dist       # 윈도우 설치 파일 (release/)
```

## 단축키

| 키 | 동작 |
| --- | --- |
| `Shift A` | 추가 메뉴 |
| `G` `R` `S` (+ `X` `Y` `Z`) | 이동 · 회전 · 크기 |
| `Tab` | 편집 모드 |
| `I` | 키프레임 넣기 |
| `F` | 선택한 것에 맞추기 |
| `Numpad 0 / 1 / 3 / 7` | 카메라 시점 / 정면 / 옆 / 위 |
| `Space` | 재생 |
| `Ctrl B` | 자르기 |
| `Ctrl S` / `Ctrl E` | 저장 / 내보내기 |
